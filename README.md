# RocketFood

Bem-vindo ao **RocketFood**! 🍔🍕🍴

O RocketFood é um projeto de um restaurante fictício criado como desafio final da [Rocketseat](https://rocketseat.com.br/). O projeto encontra-se atualmente em sua versão inicial, com algumas funcionalidades ainda em desenvolvimento. Esta versão inclui um frontend interativo e um backend básico, oferecendo uma experiência de usuário essencial com dois tipos de perfis:

- **Admin**: Permite criar, visualizar, editar e apagar um prato a qualquer momento no sistema.

- **Customer**: Permite visualizar todos os pratos cadastrados e, quando clicar em um prato, será redirecionado para uma nova tela com informações mais detalhadas sobre ele.

Tenho trabalhando na implementação de funcionalidades adicionais para aprimorar ainda mais a experiência do usuário.

## Visão Geral

- **Frontend (Web)**: A interface de usuário onde os clientes podem explorar o menu, buscar por pratos ou ingredientes. Desenvolvido com [React](https://reactjs.org/) e outras tecnologias modernas para garantir uma experiência de usuário fluida e agradável.

- **Backend (Server)**: O núcleo do sistema, responsável por gerenciar a criação, atualização, remoção e visualização dos pratos e realizar interações com o banco de dados. Desenvolvido com [Node.js](https://nodejs.org/) e [Express](https://expressjs.com/) para garantir um desempenho eficiente e uma API segura.

## Estrutura do Projeto

- **Frontend**: Encontre o código do frontend na pasta `web`. Aqui você encontrará informações sobre a stack utilizada, as funcionalidades implementadas e as instruções para rodar o projeto.

- **Backend**: Encontre o código do backend na pasta `server`. Esta pasta contém detalhes sobre as tecnologias usadas, a estrutura da API, e como configurar e executar o servidor.

## Documentação e Execução

Para informações detalhadas sobre como configurar e rodar cada parte do projeto, por favor, consulte as respectivas pastas `web` e `server`.
